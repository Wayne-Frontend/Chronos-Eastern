## 5. 已知限制

1. 天德在二、五、八、十一月只记乾、坤、艮、巽四维，本版本不自行折算为具体日支，因此这些月份不产生天德日。
2. 月刑已与五张月表交叉核对，另有七张常规月份月表尚待逐张复核。
3. 宜忌并见时采用卷十常例“两者皆不注”，返回 `unresolved` 并不列入结果；德神例外和六等第尚未实现。
4. `lunar-javascript@1.7.7` 的 Android 真机验证与 1901–1948 历史颁行历表一致性仍待补强；远期近午夜风险样本已逐例核对（2051／2083／2084／2085 与香港天文台逐年表一致，2057-09-28 新月一日差已记录，见评估文档 5.3）。
5. V1.0 尚未实现分享、隐私说明、备案信息展示和发布清单；完整版免责声明已在关于页实现并提交，但尚未视觉验收。
