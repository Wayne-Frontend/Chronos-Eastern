## 5. 已知限制

1. 天德在二、五、八、十一月只记乾、坤、艮、巽四维，本版本不自行折算为具体日支，因此这些月份不产生天德日。
2. 月刑已与五张月表交叉核对，另有七张常规月份月表尚待逐张复核。
3. 宜忌并见时采用卷十常例“两者皆不注”，返回 `unresolved` 并不列入结果；德神例外和六等第尚未实现。
4. `lunar-javascript@1.7.7` 的 Android 真机验证、远期近午夜风险样本和 1901–1948 历史颁行历表一致性仍待补强。
5. V1.0 尚未实现分享、完整版免责声明、隐私/备案入口和发布清单。
