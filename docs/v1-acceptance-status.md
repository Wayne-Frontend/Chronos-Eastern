## 5. 已知限制

1. 天德在二、五、八、十一月只记乾、坤、艮、巽四维，本版本不自行折算为具体日支，因此这些月份不产生天德日。
2. 月刑已与五张月表交叉核对，另有七张常规月份月表尚待逐张复核。
3. 宜忌并见时采用卷十常例“两者皆不注”，返回 `unresolved` 并不列入候选；德合例外和六等第尚未实现。
4. 1901–1948 历史区间的官方颁行历表一致性仍待补强；远期近午夜风险样本已逐例核对，秒级节气精度因权威公开资料只到分钟而不作保证。
5. 当前代码未实现中性日期分享、独立隐私说明页面和备案号展示；后台提审信息的具体值未写入仓库，后续维护不能据此文档反推平台配置。

## 6. 后续顺序

1. 等待并记录微信审核结果；若被退回，按审核意见做最小范围修复。
2. 将实际服务类目、备案状态、隐私保护指引和审核反馈补录到合规台账。
3. 决定是否在后续版本补充中性分享、独立隐私说明与备案号页面展示。
4. 继续保持四事项有限支持，不在 V1.0 审核期间新增事项或调整规则口径。
