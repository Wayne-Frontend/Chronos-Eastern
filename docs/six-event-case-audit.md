# 六事项独立日期案例复核

核对日期：2026-10-19（Asia/Shanghai）。本轮针对已开放的出行、开业、搬家、婚嫁、订婚、提亲六个事项，检查同一日期能否按**各自**的卷十一用事条目、义例和卷十裁决得出不同结论。配套回归见 [`tests/six-event-case-audit.test.ts`](../tests/six-event-case-audit.test.ts)。

## 依据与方法

- 用事原文以[卷十一影印本](https://commons.wikimedia.org/wiki/File:CADAL06056511_%E6%AC%BD%E5%AE%9A%E5%8D%94%E7%B4%80%E8%BE%A8%E6%96%B9%E6%9B%B8%C2%B7%E5%8D%B7%E5%8D%81%E4%B8%80~%E5%8D%B7%E5%8D%81%E4%BA%8C.djvu)及[来源台账](sources-ledger.md)既有校勘为准；本轮用[卷十一转录](https://zh.wikisource.org/zh-hant/%E6%AC%BD%E5%AE%9A%E5%8D%94%E7%B4%80%E8%BE%A8%E6%96%B9%E6%9B%B8_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B711)复查条目定位，没有重新逐帧校读卷十一所有条目。
- 月建、建除的起法及交节叠值记载见[卷四《建除十二神》](https://zh.wikisource.org/zh-hant/%E6%AC%BD%E5%AE%9A%E5%8D%94%E7%B4%80%E8%BE%A8%E6%96%B9%E6%9B%B8_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B704)；归忌「四孟在丑、四仲在寅、四季在子」及按语仅忌般移、远回，见[卷六《归忌》](https://zh.wikisource.org/zh-hant/%E6%AC%BD%E5%AE%9A%E5%8D%94%E7%B4%80%E8%BE%A8%E6%96%B9%E6%9B%B8_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B706)。
- 宜忌并见、逐项解除及定忌的现行实现对照[卷十《宜忌》](https://zh.wikisource.org/zh-hant/%E6%AC%BD%E5%AE%9A%E5%8D%94%E7%B4%80%E8%BE%A8%E6%96%B9%E6%9B%B8_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B710)及[既有裁决影印审计](conflict-adjudication-audit.md)。2026 年日期事实由项目历法服务产生，本轮未另找一套 2026 年逐日历书复算全部日柱。

此处把“独立”落实为两层：先按原书确认哪些规则属于哪个用事，随后固定真实日期的月柱、日柱、建除和规则命中，断言六包各自的结论与裁决轨迹。状态回归不是对整部古籍的重新校勘，也不把一包结果当成另一包的期望。

## 同日六事项结论

`宜`＝进入候选；`排`＝明确排除；`未决`＝宜忌并见而未获裁决；`无`＝无已收录条款命中。日期为公历 2026 年。

开业另补一例**并见定忌**：06-06 为午月辛亥，五富宜项与小耗、劫煞忌项同日；[卷十《小耗》](https://zh.wikisource.org/zh-hant/%E6%AC%BD%E5%AE%9A%E5%8D%94%E7%B4%80%E8%BE%A8%E6%96%B9%E6%9B%B8_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B710)明确子午卯酉月与劫煞并仍忌，故开业为「排」，不是未决或候选。至此六包均有宜、排、未决、解除、定忌及交节边界样本。

另核立春前后：02-03 为己丑月，02-04 立春当日为庚寅月；六包在 02-04 均命中寅月天吏。这里**只验证既定的“交节当天整日取新月”代码口径**，不声称它已解决原书“交节叠两值日”的全部解释问题。

## 本轮结论与后续边界

1. 上述同日案例未发现六包互相串用条目、把可解除忌项扩散到其他忌项，或把未决日误列为候选的情况。新增回归见测试文件；没有改动规则数据、引擎或包版本。
2. 这组案例覆盖六事项各自的宜、排、未决及交节；`无匹配` 在同日对照中亦有样本。它是**代表性抽样**，不能由此推断六包所有规则和原书日页已逐条再核。
3. 下一步仍须分别处理[缺口清单](rule-gap-inventory.md)中的专项：婚嫁“不将”逐月表与六月戊午；开业大耗／小耗的原文归并；订婚、提亲三合十二月讹字与五合／五离；搬家归忌的更多月组。卷十六等第表与交节双值另作研究，证据充足后才可改变结论。
