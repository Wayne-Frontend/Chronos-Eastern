# 宜忌冲突裁决审计（《协纪辨方书》卷十）

> 审计日期：2026-10-09（Asia/Shanghai）
> 审计对象：`xjbf-travel` 规则包中"纳入与排除同级命中"（`unresolved`）的裁决依据
> 审计边界：只核对《协纪辨方书》卷十「宜忌」对**吉凶并见**给出的取舍规则，以及它能否、应否被本项目实现。本文不修改业务代码或规则数据。

## 1. 结论摘要

1. **原书明确反对"任一忌覆盖任一宜"。** 卷十篇首批评旧历「凡吉神所宜之事，一遇凶煞则无论轻重而概忌之，尤为未当」。本项目把"忌优先"当默认语义是错的，把冲突日判为 `unresolved` 反而是**正确的保守做法**。
2. **卷十的常例正是"互相不注"**：影印本第 140 帧「凡所忌者則不注宜，所宜者亦不注忌，不與德合併，如常例」。即宜忌并见且无德神介入时，宜、忌**同时不生效**。这与我方 `unresolved`（该日不进入结果）语义一致，不是权宜之计。
3. **例外由德神触发，但形制复杂**：与天德／月德／天德合／月德合并临时，忌会被削减为一份**剩余清单**（第 140 帧「止忌安撫邊境選將訓兵出師求醫療病，餘皆不忌」），且「如遇德犹忌之日则仍注忌」——德并非万能。
4. **裁决在原理上可判定，但需要一件本项目尚未录入的文物**：卷十末尾的**宜忌等第表**（影印本第 222 帧起）。它是一张「忌神煞 × 六等第」的矩阵，单元格以「某月＋某建除日」定位，配合平日条下的六等第定义使用。
5. **等第表覆盖不了本项目的一部分冲突。** 「巳日」不在卷十的忌项清单中（卷十忌项不含巳日），它是卷十一「行幸遣使」条目自带的日支忌。因此"天喜（成日，宜）撞巳日（忌）"这类冲突**不在卷十裁决体系的射程内**，即使录入等第表也无解。
6. **建议：本版维持 `unresolved`，不实现六等第。** 理由见 §6：射程不全、录入成本高、且需要规则引擎新增一类"跨条件裁决"能力。当务之急是把冲突的**原因**按卷十的常例如实讲清楚，而不是急着替用户下结论。

## 3. 卷十的裁决体系

### 3.1 篇首立场：反对一概以忌压宜

转录所记篇首大意：神煞之宜忌各随其性，力有相胜则情随力变；旧历「凡吉神所宜之事，一遇凶煞则无论轻重而概忌之，尤为未当」。

### 3.2 六等第（平日条下，转录）

| 等第 | 原文 | 结果 |
| --- | --- | --- |
| 上吉 | 足胜凶 | 从宜不从忌 |
| 上次吉 | 足抵凶 | 遇德从宜不从忌；不遇从宜亦从忌 |
| 中等 | 吉不抵凶 | 遇德则吉胜，从宜不从忌；不遇从忌不从宜 |
| 中次 | 凶胜于吉 | 遇德始相抵，从宜亦从忌；不遇从忌不从宜 |
| 其下 | 凶又逢凶 | 遇德从忌不从宜；不遇诸事皆忌 |
| 最下 | 凶叠大凶 | 遇德仍诸事皆忌 |

并注明「除建破等日条例简易及专忌之日无庸分别外，餘分为六等」。**建日、破日等不参与六等第分级**——这与本项目现有冲突直接相关：月破类冲突不落在这套分级内。

### 3.3 常例：并见即两不注（影印第 140 帧）

> 凡所忌者則不注宜，所宜者亦不注忌，不與德合併，如常例。

即：在**没有德神介入**的默认情形下，宜与忌同时失效。这就是本项目的 `unresolved`。

### 3.4 例外：德合并临（影印第 140 帧）

德合并临时，忌被削减到一份剩余清单，其余不再计忌：

> 寅申巳亥月值相日，亥月又值時德，六合止忌安撫邊境選將訓兵出師求醫療病，餘皆不忌。申月值月害與天德、月德合併，亦止忌安撫邊境選將訓兵出師求醫療病，餘皆不忌。

两个要点：

- 剩余清单是**逐月、逐神煞、逐用事**的，不是一条通则；
- 「如遇德猶忌之日則仍註忌」（第 228 帧）——存在德也压不住的专忌。

### 3.5 天赦、天愿的特殊地位（影印第 100 帧）

> 天赦、天願皆合干支取義，其氣純，其力大，乃日之最吉者，能解諸凶，故特表之。

这条支持一个方向：**天赦日遇忌时，宜可能压过忌**。但它给的是定性表述，没有给出"解诸凶"的边界（哪些忌能解、哪些不能），单凭本帧不足以直接编码。

### 3.6 宜忌等第表（影印第 222 帧）

表体为矩阵：列头是忌方神煞（月煞、月刑、月害、月厭、大時、天吏等），行是六等第，单元格以「某月组＋某建除日」定位，例如月厭列下见「寅申月　破日」「巳亥月　滿日」，月害列下见「子午月　閉日」。

**该表的输入恰好是本项目已具备的事实**（节令月支 + 建除），因此原理上可计算。但它跨多帧、覆盖约五十个忌神煞，且需与 §3.2 的分级、§3.4 的德合判定合用。

## 4. 与本项目现状的对照

| 卷十的规定 | 本项目现状 | 判断 |
| --- | --- | --- |
| 反对"忌一概压宜" | 引擎不设忌优先，同级命中返回 `unresolved` | 一致 |
| 常例"宜忌两不注" | `unresolved` 日不进入结果，仅计数 | **一致** |
| 德合并临则忌削减 | 未实现 | 缺口 |
| 六等第分级取舍 | 未实现 | 缺口 |
| 天赦"能解诸凶" | 未实现，天赦遇忌仍判 `unresolved` | 缺口（偏保守） |
| 建破等日"条例简易"不参与分级 | 月破冲突同样返回 `unresolved` | 一致（本就不该套分级） |

结论：**现有的 `unresolved` 不是权宜之计，而是与原书常例相符的默认语义。** 缺口在于原书给出的若干例外（德合、天赦），本项目一律按常例处理，因而偏保守——会少给一些日期，但不会给出原书未支持的结论。

## 5. 可裁决性的两个硬缺口

### 5.1 射程不全：巳日类冲突不在卷十体系内

卷十的忌项清单不含「巳日」。巳日来自卷十一「行幸遣使（出行同）」条目自身的忌项，属**用事自带的日支忌**，不属于卷十按神煞分级的对象。

因此本包已有的这类冲突——天喜（成日，宜）撞巳日（忌）、吉期（除日，宜）撞巳日（忌）——**即便完整录入等第表也无法裁决**，除非卷十一自身或别处另有说明。当前样本中这类冲突占比不低。

### 5.2 形制不匹配：需要"跨条件裁决"能力

现有规则 DSL 的 `when.all` 是合取式，`evaluateDay` 也只做"逐条求值再按同级冲突分类"。六等第要求的是**在冲突发生之后，再按（月支，建除日，涉及的神煞集合）查表定等**，属于对冲突结果的二次裁决，不是单条规则能表达的条件。

实现它意味着在规则引擎里新增一类裁决层，并按 §3.6 录入矩阵数据。这是比第三阶段那次 DSL 扩展大得多的改动，且会引入一份**未经本项目逐格核对**的表格。

## 6. 建议

1. **本版维持 `unresolved`，不实现六等第。** 它符合原书常例；在射程不全（§5.1）与形制不匹配（§5.2）两个问题解决前强行实现，只会得到一份"部分日子按新法、部分日子按旧法"的混合语义，比现在更难解释。
2. **把冲突原因按卷十常例如实讲给用户**，而不是让它显得像缺陷。当前找日子页已列出冲突日期并可跳详情；详情页的措辞可再补一句依据：宜忌并见且无德神裁决时，原书常例即两不注。
3. **若将来要实现，顺序应是**：先补齐三十二项原语 → 再逐格核对并录入宜忌等第表 → 先只实现德合并临这一条例外（它的输入是节令月支与日干支，本项目已具备）→ 最后才考虑六等第。**天德已于 2026-10-12 定案**（四仲月为卦位不判值日，底本自身如此，见 `docs/travel-rule-audit.md` §8.12），不再是德合例外的前置障碍；实际勘察后的试点切法见 §6.1。
4. **`unresolved` 的计数与清单要继续保留**，它是这套保守语义可被用户检验的唯一出口。

## 6.1 试点方案（2026-10-12 勘察后追加）

**勘察结论**：卷十的裁决体系有**两种同内容的形态**，都可读、都可计算——

1. **逐神煞的散文判定句**（凶神区每个条目的正文）：先列该神煞所忌的用事清单，再按「月组＋该神煞在本月组所值的建除日」给出判定，例如刼煞条：
   「寅申巳亥月值收日……寅申月又值六合，止忌安撫邊境選將訓兵出師求醫療病，餘皆不忌；……辰戌丑未月值除日相日與天德月德天德合月德合併，止忌……餘皆不忌；不與德神併，凡所忌者則不註宜，所宜者亦不註忌」。
2. **宜忌等第表**（影印本第 222 帧起，本轮已见其形制）：把上式的结论按神煞分列成矩阵，格内以「月＋建除日＋（德神）」定位。表用等第简写，散文更明确，**编码以散文为准、表作交叉核对**。

**判定结果只有四类**，正好对应引擎需要的语义：

| 原书措辞 | 语义 | 引擎动作 |
| --- | --- | --- |
| 「與〈德神〉併則不忌」 | 该忌神当日不忌 | 冲突消解 → 可判 `pass` |
| 「止忌〈甲、乙、丙〉，餘皆不忌」 | 只对所列举的用事仍忌 | 用事不在残余清单内即消解 |
| 「如常例」「不註宜亦不註忌」 | 无德神介入的默认 | 维持 `unresolved`（现状） |
| 「諸事皆忌」「雖與德合併猶忌」 | 德神也压不住 | 维持 `excluded` |

**输入全部可得**：月支、建除、以及「当日同时当值的神煞集合」（天德、月德、天德合、月德合、天愿、天赦、三合、六合、六仪等）——后一组正是现有 `MONTH_GOD_TABLES` 的各张表，判定时逐表比对即可，**不需要任何新的历法输入**。

**试点切法**（建议）：以「开业」为对象，因为它是唯一不含天德、且其冲突恰好落在最常见组合上的包。步骤：

1. 开业忌项 19 个神煞逐个取散文条款，**逐条回影印核对**（转录只用于定位）；
2. 编码为一张「忌神煞 × 月组/月 × 建除 → {要求的神煞组合，结果}」的裁决表；
3. 引擎在 `unresolved` 判定前先查表：条款条件满足则按上表收敛，未编码的神煞仍走常例；
4. 以 90 天窗口对比前后候选日与冲突日数量，作为试点成效证据；
5. 先做高频条款（已初步看到九空「寅申月值滿日、子午卯酉月值開日，與月德天德合月德合併則不忌」、四耗、大時、月厭、月害、天吏等），其余 19 条分批补齐；**分批期间的限制语必须写明"例外只实现了哪几条"**，不得让用户以为例外已全。

**风险与边界**：卷十散文的转录尚未逐字校对（本文 §7），编码前每条须回影印；且 §5.1 的射程缺口不受本试点影响——用事自带的日支忌（巳日、亥日等）仍无裁决依据，永远走常例。

**第四批：最后一处核对闭合并改判（2026-10-12）**：

1. **归忌**已在影印本第 202 帧核对：忌般移、遠迴，与德合赦愿并「猶忌」，**无解除条款**。至此六事项忌项的全部神煞条款核对闭合。（该按语「并忌進人口納財豎柱上梁，其义不伦，故删」2026-10-12 复查时确认属**大煞**，不属归忌，更正见第五批第 4 条。）
2. **改判**：六个规则包 `partial` → `complete`，事项 `limited` → `supported`（版本：travel 1.18.0、relocation 1.1.0、opening 1.1.0、marriage 1.3.0、engagement 1.1.0、proposal 1.1.0）。**判据**：条目收全 ＋ 卷十的裁决例外（解除、定忌、转致、整日诸事皆忌）逐条落实 ＋ 未给依据者如实标注。`supported` 之下 chip 的「有限收录」标记与三处覆盖范围披露语按设计自动消失（`getStatusBadgeText` 对 supported 返回空串、`describeCoverage` 对 complete 返回空），但 `statusNote` 与各条 `limitations` 仍如实上屏。
3. **仍如实保留的两处边界**：天德四仲月不判值日（底本自身的记法）；巳日、亥日这类用事自带的日支忌不在卷十体系内（原书未给裁决依据）。二者都不是未实现的缺口，而是底本的实情，继续写在限制语里。

**第五批：「猶忌」与整日排除的收尾（2026-10-12 当日）**：

1. **「與德合併猶忌」一类条款定案为 `exclude`（定为忌）**，此前的编码把这类支路写成 `normal`（乃至记「无解除条款」而不编码），与类型定义里的「`exclude`＝原书明言『諸事皆忌』或『雖與德合併猶忌』」自相矛盾。三条判据把它定为忌：
   - 铺注条例（影印本第 228 帧）「凡吉凶相抵……**如遇德猶忌之日則仍註忌**」——德神压不住的犹忌之日照旧注忌，不是两不注；
   - 各该条按语说明德神不能化解：四忌四窮「此八日皆以極旺為凶，故德神不能化解」（第 194 帧）、往亡「雖值德合赦願不能無疑，故與併猶忌」（第 203 帧）、天贼「與德合義不相屬，故與併猶忌」（第 189 帧）；
   - 对文措辞：原书该给常例时写的是「如常例」（天吏、月厌等条），「猶忌」是刻意不同的说法。
   本轮逐条回看影印并编码：天贼（第 189 帧；小注「赦願不得與天賊併」，故条件只取天德、月德、天德合、月德合四神）、四废（第 192 帧「與德合併猶忌，與月破併諸事皆忌」，两支路都是忌）、四穷与四忌（同《四忌四窮》条，第 194 帧；原句只列月德、天德合、月德合三神、未列天德，表从原句）、八专（第 208 帧）、往亡（第 203 帧）、归忌（第 202 帧）、小耗（子午卯酉月值劫煞，第 188 帧）。**德神不在场时仍是常例**（第 140 帧「不與德合併，如常例」），故每条犹忌支路都写明 `requiresAny`，并保留兜底 `normal` 支路。
2. **「四忌」此前三包都没有条款**：《四忌四窮》是四忌与四穷的合条，而条款只挂在「四穷」名下。本轮把犹忌句补挂到「四忌」；解除支路（「惟正月乙亥與天願併」）仍只属四穷——乙亥是四穷日，四忌没有解除支路。
3. **整日「諸事皆忌」改为先于一切判定**（引擎改动）：该表原先只在「宜忌并见」分支里查，2026 年有两日因此漏判——2026-03-06（卯月己卯，陰道衝陽）的出行、搬家，与 2026-10-27（戌月甲戌，陰位）的出行、开业、提亲，曾在无忌项命中时被输出为「宜」或「未匹配」。今改为 `evaluateDay` 的首个判定，缺输入（`unknown`）也不例外——原书明言「與月德併仍諸事皆忌」，吉神与缺输入都不能翻。
4. **更正第四批的一处记错**：「并忌進人口納財豎柱上梁，其义不伦，故删」这条按语属**大煞**，不属归忌——第 201 帧末列的是「大煞」条目名与「忌安撫邊境選將訓兵出師」，第 202 帧首列是它的判定句「與德合併猶忌」与小注「赦願不得與大煞併」，按语紧随其后；归忌条目自第 202 帧第三列起，只有「忌般移遠迴」与「與德合赦願併猶忌」两句，自身无按语。
